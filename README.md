# Projeto de Fundamentos do TypeScript

## Visão Geral
Este projeto serve como uma introdução aos conceitos fundamentais do TypeScript, um superset de JavaScript com tipagem estática que adiciona tipos opcionais à linguagem.

## Principais Recursos
- **Tipos**: Entenda os vários tipos no TypeScript, incluindo primitivos, arrays, tuplas e enums.
- **Interfaces**: Aprenda a definir e implementar interfaces para reforçar a estrutura de um objeto.
- **Classes**: Explore a programação orientada a objetos no TypeScript com classes, herança e modificadores de acesso.
- **Generics**: Familiarize-se com generics para criar componentes reutilizáveis que funcionam com diferentes tipos de dados.
- **Módulos**: Descubra como organizar seu código usando módulos e namespaces.
- **Inferência de Tipo**: Entenda como o TypeScript infere tipos automaticamente.

## Primeiros Passos
### Pré-requisitos
- Conhecimento básico de JavaScript.
- Node.js instalado em sua máquina.

### Instalação
1. Clone o repositório:
   ```bash
   git clone https://github.com/obrnocsta/service-end-to-end.git
   cd service-end-to-end
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```

### Executando o Projeto
Para executar o projeto, utilize o seguinte comando:
```bash
npm start
```
