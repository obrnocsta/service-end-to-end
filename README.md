# TypeScript Fundamentals Project

## Overview
This project serves as an introduction to the fundamental concepts of TypeScript, a statically typed superset of JavaScript that adds optional types.

## Key Features
- **Types**: Understand the various types in TypeScript, including primitives, arrays, tuples, and enums.
- **Interfaces**: Learn how to define and implement interfaces to enforce the structure of an object.
- **Classes**: Explore object-oriented programming in TypeScript with classes, inheritance, and access modifiers.
- **Generics**: Get acquainted with generics to create reusable components that work with different data types.
- **Modules**: Discover how to organize code using modules and namespaces.
- **Type Inference**: Understand how TypeScript automatically infers types.

## Getting Started
### Prerequisites
- Basic knowledge of JavaScript.
- Node.js installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/obrnocsta/service-end-to-end.git
   cd service-end-to-end
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Project
To run the project, execute the following command:
```bash
npm start
```
